# Support

Use GitHub Issues for questions, bug reports, and feature requests. Support is provided on a
best-effort basis and no response-time commitment is made.

Before opening an issue, search existing reports and review the [README](README.md), the
[example walkthrough](demo/ExampleFunction/README.md), and the
[implementation journal](docs/journal/README.md). Include the package version, target framework,
Azure Functions Worker package versions, and a minimal reproduction where possible.

Do not post security vulnerabilities, secrets, connection strings, or private application code in
an issue. Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting.
