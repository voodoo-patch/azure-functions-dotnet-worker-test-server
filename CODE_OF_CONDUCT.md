# Code of Conduct

## Our commitment

We are committed to a respectful, harassment-free community for everyone, regardless of
experience level, identity, background, or viewpoint. Participation in project spaces must be
professional, constructive, and welcoming.

## Expected behavior

- Use inclusive and respectful language.
- Give and accept feedback in good faith, focusing on the technical work rather than individuals.
- Respect differing viewpoints and help newcomers participate productively.
- Protect private information and report security concerns through the private process described
  in [SECURITY.md](SECURITY.md).

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized language or imagery,
publication of private information, deliberate disruption, and other conduct that a reasonable
person would find hostile or unsafe are not acceptable.

## Scope and enforcement

This code of conduct applies to issues, pull requests, discussions, review comments, and other
project-controlled spaces. Maintainers may remove content, limit participation, or take other
appropriate action for violations.

For conduct concerns that cannot be raised safely in public, use this repository's private
reporting control in the GitHub **Security** tab. Before the first public release, maintainers
must enable GitHub private vulnerability reporting so this route is available. Do not disclose
vulnerability details in a public issue.
