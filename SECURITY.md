# Security Policy

## Supported versions

Security fixes are evaluated for the latest released package version. Pre-release builds and
unsupported Azure Functions Worker versions may require an upgrade before a fix can be considered.

## Reporting a vulnerability

Do not report vulnerabilities in a public GitHub issue. Use the repository's **Security** tab and
select **Report a vulnerability** to submit a private report to the maintainers. Include a clear
description, affected package and version, reproduction steps or proof of concept, impact, and
any suggested mitigation.

Maintainers will acknowledge reports, assess impact, and coordinate disclosure through that
private thread. GitHub private vulnerability reporting must be enabled in the repository settings
before the first public release; it is a release prerequisite, not a substitute for public issue
support.
